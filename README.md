🏦 Bank Customer Churn Analysis

📌 Project Overview

Bank Customer Churn Analysis is a Python-based data analytics project developed as part of a Data Science & Machine Learning Internship. This project analyzes customer behavior, identifies churn patterns, and provides meaningful business insights through data preprocessing, exploratory data analysis (EDA), machine learning, and interactive visualizations.

🎯 Project Objectives
Analyze customer churn behavior.
Identify factors affecting customer retention.
Perform customer segmentation based on demographics.
Predict customer churn using Machine Learning.
Visualize churn trends using professional dashboards.
